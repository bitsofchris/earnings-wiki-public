# CALL - MSFT 2026-Q2 [fiscal FY26-Q4] (2026-07-29) — Nadella, Amy Hood

*Source caveat: distilled from a secondary transcript extract (Investing.com); primary docx not yet fetchable. Verify quotes against the primary when it lands.*

## TLDR

The AI-capex-ROI question answered with receipts: Azure accelerated to +43% and crossed $100B annually, Copilot seats and agent registrations are compounding, and the CFO's core claim is that demand exceeds supply so every efficiency gain monetizes instantly. Guidance says the acceleration continues (Azure +45% cc in FY27) while capex steps up to $50B+/quarter. Stock up after hours from a washed-out base.

## Numbers

- Revenue $90.0B +18% (est $87.6B); EPS $4.74 (est $4.24). FY26: revenue $331B +18%, op income $155B +21%.
- Azure +43% Q4, +41% FY, **>$100B annual**; Microsoft Cloud $214B +27%.
- Segments: Intelligent Cloud $39.3B +32% · P&BP $37.8B +14% · More Personal Computing $12.9B −4%.
- Capex $41B in Q4; FY27: $50B+/quarter.
- Copilot: M365 30M+ paid seats, **net adds doubled sequentially**; GitHub Copilot 50M users; Agent 365 **40M agents registered in two months**.
- Enterprise breadth: Fabric 40k+ customers, Foundry 100k+, PostgreSQL +55%, ~90% of Fortune 500 grounding agents via Foundry/Fabric.

## Commentary (verbatim, per secondary source)

- Nadella: **"You've got to keep your harness separate from the model."** / **"Every model is substitutable."** Enterprises keep "token capital," mix frontier + MAI + custom.
- Nadella on the product arc: "chat to Copilot to autopilots."
- Hood: **"Demand continues to exceed available supply"**; fleet efficiency gains "quickly monetized"; gross margin down YoY on Azure mix + AI infra investment.
- MAI-Cyber-1-Flash: "Mythos-level performance with 50% less cost" — first-party models as the cost lever.
- Nadella on enterprises: build "learning machines," don't outsource core IP.

## Guidance (FY27)

- Revenue +16–17% (Q1 $89.85–90.95B); op margin ~flat; opex mid-to-high single digits.
- Azure +45% cc; Intelligent Cloud +33–34%; M365 commercial +16% adj; Windows OEM declining low-20s.
- Capex growing YoY; $50B+ in Q1.

## Surprises

- **Accounting assist:** data-center useful life extended 15→25 years + finance→operating lease reclassification (~$175B of 2026 capex presentation) — flatters the flat-margin guide; economics vs optics worth tracking.
- Azure acceleration attributed partly to *efficiency* (more sellable capacity from the same fleet), not just new builds.
- Agent 365 as a governance/registry product — the control plane for agent sprawl is itself a SKU.
- Security reframed as an always-on agentic system (red/blue/green-team agents).
